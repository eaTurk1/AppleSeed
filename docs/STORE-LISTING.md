# AppleSeed

Free, open-source remote desktop access over Tailscale. One edition includes all remote controls, monitor selection, stream quality, timers, the supported Mac secure-unlock shortcut, display controls, and optional browser Web Portal.

Connect to a computer you own or are authorized to control. Tailscale is required for the private host/client path. The optional Web Portal requires separately configured HTTPS hosting and a temporary code enabled by the owner.

No purchase or developer account is required. Optional external tips support development without changing app features. Passwords and native OS permissions still apply. AppleSeed cannot power on an offline computer or unlock FileVault's preboot screen.

Android 9+, macOS 13+ companion on Apple silicon, desktop ports for Windows/Linux, and native iOS/iPadOS source targeting 16+. iOS App Store/TestFlight availability depends on signing and review; do not present an unsigned build as publicly installable.
