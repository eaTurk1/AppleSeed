# AppleSeed 2.1.0 validation

- 90 shared tests pass. New coverage includes three-finger gesture recognition and cancellation, suppression of remote clicks/keys, monitor mapping, Chrome tab selection after reordering, closed-tab rejection, and the private owner/session boundary on the Apps API.
- The signed Android APK passes signature, alignment and 13 bundled-client asset checks. Emulator instrumentation exercises the Apps sheet, browser expansion, exact tab activation, non-browser window selection, monitor follow, filtering, metadata cleanup, gesture opening, and repeated immediate close/reopen. Existing fullscreen, theme, clipboard, background lifetime, timer and notification checks also pass.
- The shared client was inspected at 412 × 915 phone dimensions. Apps is directly available in the toolbar without page scrolling; the app/window/tab list scrolls within its own sheet. Existing fullscreen controls remain available.
- The installed Mac companion was exercised with real running applications and Chrome tab enumeration. Real Chrome tab activation was verified through the shared interface. Real non-browser window activation was also verified. Finder enumeration verified the process-start identity check, including applications without a launch date. App references bind to both PID and kernel process start time to reject process reuse.
- Browser operations use fixed, allowlisted scripting with stable window/tab IDs. No URLs, browser page scripts, page content, cookies, history or passwords are read. A missing Automation permission has an explicit request path. Browser workers time out without occupying the main unlock handler.
- The Mac companion and private service were updated locally and the service restarted successfully. Screen Sharing remains online and both host displays are detected. Existing private Tailscale and public Web Portal routing were preserved.

Android tests use a disposable emulator, synthetic credentials and mock remote data. They do not claim a physical Samsung phone test. Window titles and availability depend on the application's Accessibility support. Individual tabs are supported for Chrome-family browsers listed in the README; Safari currently exposes windows only. Other platform downloads remain the previously validated 2.0.0 previews. App switching is currently a private Mac-host feature, not a public Web Portal control.
